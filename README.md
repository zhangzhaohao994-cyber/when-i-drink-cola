# when-i-drink-cola# 当我喝可乐的时候 / When I Drink Cola

A lightweight, mobile-friendly music player for the Internationale / Hard Acid Techno version. Duration 4:06, 138 BPM. Includes five-language electronic singing, MP3 and 24-bit WAV masters, and a reproducible audio project archive.

Static HTML, CSS and JavaScript, with no external dependencies or trackers. GitHub Pages serves the root of `main`. Browser audio controls provide playback, seeking and volume. Audio is fetched only when playback is requested. Lyrics highlight in the supplied language order.

Melody reference: [The Internationale, John Chambers ABC collection](https://trillian.mit.edu/~jc/music/abc/anthem/Internationale.abc). All sung lyrics are the five user-supplied cola sentences. No recording of the original anthem was sampled.


Illustrated cover: original generated industrial/cola scene with accessible five-language overlay; includes a self-contained SVG poster download. The Chinese cover caption is 当我在喝可乐的时候，什么也没有发生。 The sung lyrics and audio are unchanged.
